# Buyora - Frontend

Ye website ka frontend hai (HTML / CSS / JS). Ye Python backend ke saath chalta hai:
upar wale folder ka `README.md` padho aur `python run.py` chalao.

- `js/products.js` : backend na chale to ye demo catalog dikhta hai
- `js/api.js`      : backend se baat karne wala code
- `js/config.js`   : backend ka address (Python server se kholne par apne-aap sahi hota hai)
